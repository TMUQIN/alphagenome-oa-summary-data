# Manuscript Data and Code Availability - author-review draft

The source osteoarthritis cis-eQTL summary relations are available through Katsoula et al. (2026; https://doi.org/10.1038/s41467-026-74993-y) and the Musculoskeletal Knowledge Portal. The paper-specific summary-data companion (GitHub URL and versioned Zenodo DOI to be inserted after publication) provides the editable Supplementary Tables S1-S6, the Figure S1 tissue-metric source table, supplementary figures S1-S2, data dictionary and documentation of the reported score transformations.

The companion is a summary-data archive, not a complete end-to-end reproduction package. It does not redistribute raw AlphaGenome API responses, the complete variant-by-candidate prediction matrix, candidate-level raw score tables, full query-level rank records, model weights, service credentials or restricted individual-level data. It does not include the complete paper-specific D0/A0/F0 analysis and figure-generation code. Accordingly, the full historical candidate-level analysis cannot be reconstructed from the public companion alone.

AlphaGenome-derived summary values and visual summaries are subject to the applicable AlphaGenome Output Terms of Use (https://deepmind.google.com/science/alphagenome/output-terms). The archive includes the supplied terms documents, a conspicuous notice and a description of modifications to the original RNA_SEQ Output. The version applicable to each historical output-generation date has not been independently established in this candidate package.

The general-purpose Gene Retrieval Validation Toolkit v0.1.0 is separately available at Zenodo (https://doi.org/10.5281/zenodo.24457343). It provides reusable validation utilities and is not the paper-specific analysis pipeline.
