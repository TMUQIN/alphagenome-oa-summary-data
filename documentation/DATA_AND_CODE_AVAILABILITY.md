# Data and code availability

The source osteoarthritis cis-eQTL summary relations are available through Katsoula et al. (2026; https://doi.org/10.1038/s41467-026-74993-y) and the Musculoskeletal Knowledge Portal, subject to the source provider's terms. The summary-data companion is archived at Zenodo (https://doi.org/10.5281/zenodo.24556013) and is also available through GitHub (https://github.com/TMUQIN/alphagenome-oa-summary-data). It contains editable Supplementary Tables S1-S6, the Figure S1 tissue-metric source table, Supplementary Figures S1-S2, data dictionaries and documentation of score transformations.

The companion does not redistribute raw AlphaGenome API responses, complete candidate-level prediction matrices, raw score tables, full query-level ranks, model weights, service credentials or restricted individual-level data. The full paper-specific D0/A0/F0 analysis and figure-generation code is not included. The historical candidate-level analysis cannot be reconstructed from the public companion alone.

AlphaGenome-derived summaries are subject to the applicable AlphaGenome Output Terms of Use (https://deepmind.google.com/science/alphagenome/output-terms). The archive includes the supplied terms documents, a conspicuous usage notice and a description of the modifications to the original RNA_SEQ Output. The historical terms version applicable to each output-generation date has not been independently established.

The general-purpose Gene Retrieval Validation Toolkit is separately available at https://doi.org/10.5281/zenodo.24457343. It provides reusable validation utilities and is not the paper-specific analysis pipeline.
